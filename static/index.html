Data & connection

Know what is loaded and when it was refreshed.

Connect live data

football-data.org is the live provider for current squads, fixtures and top scorers across every competition on its free tier.

Unchecked, the key stays only in this local server's memory until it stops and is never written anywhere. Checked (the default), it's saved to a .env file in the project folder on this computer only — never in your browser, never synced, and never sent anywhere but football-data.org.

Get a football-data.org key ↗

Current-season access depends on your plan. A complete twelve-competition import can exceed a free daily quota. Completed pages are cached so an interrupted import can resume.

Coverage limits

football-data.org supplies squads, fixtures and competition top-scorer goals/assists. It does not supply ratings, xG, xA, tackles, pass accuracy or progressive actions — those remain unknown in live mode rather than estimated.

The demo contains 60 historical, synthetic profiles with invented ratings for illustration. Live imports have no 60-player cap and load all available squads and player pages.
